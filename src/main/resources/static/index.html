样例：初始纵向力矩 0，三舱位置 −20 / 0 / +20 m、待卸 20 / 10 / 20 t； 压载仅中舱 ±10 t/h；力矩限 ±100 t·m；两台岸桥各 ≤10 t/h， 不得同舱或交叉（相邻舱 H1-H2、H2-H3 禁同时，仅两侧 H1+H3 可并行）。 力矩递推 M′ = M − Σ 卸货量×舱位 + Σ 压载增减×压载舱位。 “建立作业案例”后可登记实测卸货量与压载回执；回执迟到时计划压载不会冒充实测。
